# IRL Guard V1 — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Un outil en ligne de commande qui prend une vidéo IRL enregistrée et produit une vidéo protégée (plaques, visages et textes sensibles masqués, écran de pause si nécessaire), en s'appuyant sur des détecteurs pré-entraînés, un OCR et le decision model Laya.

**Architecture:** Paquet Python `irl_guard` en modules à responsabilité unique : sources → échantillonnage → perception → suivi → state → décideur → hystérésis, puis planification par image, rendu et remux audio. Le traitement se fait en deux passes. La passe 1 analyse les images échantillonnées et écrit un journal JSONL. La passe 2 relit la vidéo, interpole les masques entre deux analyses et rend la sortie.

**Tech Stack:** Python 3.12, uv, PyTorch CUDA (cu128), Ultralytics YOLO, trackers (ByteTrack), RapidOCR (onnxruntime), NudeNet, OpenCV, httpx, pydantic v2, PyYAML, Typer, imageio-ffmpeg, pytest.

**Spec:** `docs/superpowers/specs/2026-10-09-irl-guard-v1-design.md` (lire avec ce plan).

## Global Constraints

- Python `>=3.12,<3.13`, environnement géré par `uv` (`uv sync`, `uv run ...`). Aucune installation dans le Python système.
- Code sous `src/irl_guard/`, tests sous `tests/`. Identifiants métier en français (`piste`, `boite`, `analyse`) comme dans la spec.
- Les seuils d'action portent sur `probabilities`, jamais sur `confidence`.
- Échec du côté sûr : toute erreur du décideur sur une piste ⇒ action `flouter` (`source = "fallback"`), jamais `diffuser`.
- Laya : `POST {url}/v1/systemone`, modèle par défaut `laya-multilingual`, budget de 1024 tokens (on vise 700 pour le `state`).
- Pas de chemin Windows en dur : `pathlib.Path` partout, le code doit tourner sur Linux et Colab.
- Les tests par défaut n'utilisent ni GPU, ni Laya, ni modèle téléchargé. Les tests marqués `gpu` (vrais modèles) et `slow` (OCR réel) sont exclus par défaut.
- Chaque commit se termine par la ligne `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

**Écarts assumés par rapport à la spec** (décidés après vérification des bibliothèques le 2026-10-09) :

1. **Échantillonnage.** Au lieu d'un hash perceptuel, on compare une empreinte réduite (niveaux de gris 160×90) par différence maximale locale, avec une ré-analyse forcée après `max_reutilisations`. Un hash perceptuel global peut ignorer l'apparition d'un petit texte, ce qui produirait une fuite.
2. **OCR et NudeNet sur CPU (`onnxruntime`).** `onnxruntime-gpu` entre en conflit avec `onnxruntime`, dont NudeNet dépend. YOLO reste sur GPU.
3. **ffmpeg via `imageio-ffmpeg`**, qui embarque son binaire. ffmpeg n'est pas installé sur la machine.
4. **ByteTrack via le paquet `trackers`** (`ByteTrackTracker`). `supervision.ByteTrack` est déprécié et sera retiré dans la 0.31.
5. **Le « faux serveur HTTP » de la spec** est un `httpx.MockTransport`, qui a le même effet sans ouvrir de port.

## Review Focus

1. **Petit texte qui apparaît dans une image jugée « inchangée ».** On attend que l'image soit ré-analysée, sans réutiliser l'analyse précédente. Test : `test_petit_texte_rend_l_image_differente` (Task 2).
2. **Réponse Laya incomplète ou étrange** (option manquante, probabilité hors de [0, 1], `score` donné en libellé ou hors échelle). On attend un repli `flouter` ou une valeur ramenée dans l'échelle, sans plantage. Tests : `test_option_manquante_donne_repli`, `test_probabilite_hors_bornes_donne_repli`, `test_gravite_libelle_et_bornes` (Task 6).
3. **Texte qui apparaît entre deux analyses**, ou qui disparaît avant la suivante. On attend un masque sur les images intermédiaires, avec la boîte disponible. Tests : `test_apparition_entre_deux_analyses`, `test_disparition_garde_la_boite_precedente` (Task 8).
4. **Boîte qui déborde de l'image ou de taille nulle après découpage.** On attend aucun plantage, et une image inchangée hors de la zone. Test : `test_boite_hors_image_ne_plante_pas` (Task 8).
5. **Vidéo d'entrée sans piste audio.** On attend une sortie vidéo valide sans audio, avec un avertissement. Test : `test_finaliser_sans_audio` (Task 9).

```python
"""Types de base partagés par tout le pipeline."""

from __future__ import annotations

from dataclasses import dataclass

import numpy as np

CLASSES_REGLE = frozenset({"visage", "plaque"})
CLASSES_CONTEXTE = frozenset({"texte", "couteau", "ciseaux", "telephone", "ordinateur"})
CLASSE_NUDITE = "nudite"


@dataclass(frozen=True)
class Box:
    x1: float
    y1: float
    x2: float
    y2: float

    @property
    def area(self) -> float:
        return max(0.0, self.x2 - self.x1) * max(0.0, self.y2 - self.y1)

    def iou(self, other: Box) -> float:
        inter = Box(
            max(self.x1, other.x1), max(self.y1, other.y1),
            min(self.x2, other.x2), min(self.y2, other.y2),
        ).area
        union = self.area + other.area - inter
        return inter / union if union > 0 else 0.0

    def expand(self, ratio: float, width: int, height: int) -> Box:
        dw = (self.x2 - self.x1) * ratio / 2
        dh = (self.y2 - self.y1) * ratio / 2
        return Box(
            max(0.0, self.x1 - dw), max(0.0, self.y1 - dh),
            min(float(width), self.x2 + dw), min(float(height), self.y2 + dh),
        )

    def lerp(self, other: Box, t: float) -> Box:
        return Box(*(a + (b - a) * t for a, b in zip(self.to_tuple(), other.to_tuple())))

    def to_tuple(self) -> tuple[float, float, float, float]:
        return (self.x1, self.y1, self.x2, self.y2)

    def to_list(self) -> list[float]:
        return [round(v, 1) for v in self.to_tuple()]

    @classmethod
    def from_list(cls, values) -> Box:
        return cls(*(float(v) for v in values))


@dataclass(frozen=True)
class Detection:
    classe: str
    conf: float
    boite: Box
    texte: str | None = None

    def to_dict(self) -> dict:
        return {"classe": self.classe, "conf": round(self.conf, 3),
                "boite": self.boite.to_list(), "texte": self.texte}

    @classmethod
    def from_dict(cls, d: dict) -> Detection:
        return cls(d["classe"], float(d["conf"]), Box.from_list(d["boite"]), d.get("texte"))


@dataclass(frozen=True)
class Frame:
    index: int
    t: float
    image: np.ndarray
```

```python
"""Configuration d'une session : chargée depuis un YAML et validée par pydantic."""

from __future__ import annotations

from pathlib import Path
from typing import Literal

import yaml
from pydantic import BaseModel, ConfigDict, Field, model_validator


class _Strict(BaseModel):
    model_config = ConfigDict(extra="forbid")


class SeuilsConfig(_Strict):
    pause: float = Field(0.5, ge=0, le=1)
    flou: float = Field(0.4, ge=0, le=1)
    hysteresis_haut: float = Field(0.7, ge=0, le=1)
    hysteresis_bas: float = Field(0.3, ge=0, le=1)
    sortie_k: int = Field(3, ge=1)
    nudite: float = Field(0.6, ge=0, le=1)
    diff_max: int = Field(6, ge=0, le=255)
    max_reutilisations: int = Field(2, ge=0)

    @model_validator(mode="after")
    def _bas_sous_haut(self) -> SeuilsConfig:
        if self.hysteresis_bas >= self.hysteresis_haut:
            raise ValueError("hysteresis_bas doit être strictement inférieur à hysteresis_haut")
        return self


class TailleConfig(_Strict):
    petite_max: float = 0.01
    moyenne_max: float = 0.05


class LayaConfig(_Strict):
    url: str = "http://localhost:8888"
    modele: str = "laya-multilingual"
    cle: str | None = None
    timeout_s: float = Field(5.0, gt=0)


class ReglesConfig(_Strict):
    categories_couteau_ok: list[str] = Field(default_factory=lambda: ["cuisine"])
    mots_offensants: list[str] = Field(default_factory=list)


class PoidsHF(_Strict):
    repo: str
    fichier: str


class DetecteursConfig(_Strict):
    objets: str = "yolo11n.pt"
    visages: PoidsHF = Field(default_factory=lambda: PoidsHF(
        repo="AdamCodd/YOLOv11n-face-detection", fichier="model.pt"))
    plaques: PoidsHF = Field(default_factory=lambda: PoidsHF(
        repo="morsetechlab/yolov11-license-plate-detection", fichier="license-plate-finetune-v1n.pt"))
    conf_min: float = Field(0.3, ge=0, le=1)
    ocr_conf_min: float = Field(0.5, ge=0, le=1)
    device: str | None = None


class SessionConfig(_Strict):
    categorie: str = "IRL"
    charte: str
    mode_domicile: bool = False
    fps_analyse: float = Field(3.0, gt=0, le=30)
    seuils: SeuilsConfig = Field(default_factory=SeuilsConfig)
    taille: TailleConfig = Field(default_factory=TailleConfig)
    masquage: Literal["pixel", "flou"] = "pixel"
    marge: float = Field(0.15, ge=0, le=1)
    maintien: int = Field(3, ge=0)
    couper_audio_en_pause: bool = True
    budget_tokens_state: int = Field(700, ge=100)
    ecran_pause: Path | None = None
    laya: LayaConfig = Field(default_factory=LayaConfig)
    regles: ReglesConfig = Field(default_factory=ReglesConfig)
    detecteurs: DetecteursConfig = Field(default_factory=DetecteursConfig)


def load_config(path: str | Path) -> SessionConfig:
    data = yaml.safe_load(Path(path).read_text(encoding="utf-8")) or {}
    return SessionConfig.model_validate(data)
```

```python
"""Sources d'images. V1 : fichier vidéo lu avec OpenCV."""

from __future__ import annotations

from collections.abc import Iterator
from pathlib import Path

import cv2

from irl_guard.types import Frame


class VideoSource:
    def __init__(self, path: str | Path):
        self.path = Path(path)
        cap = cv2.VideoCapture(str(self.path))
        if not cap.isOpened():
            raise FileNotFoundError(f"Impossible d'ouvrir la vidéo : {self.path}")
        self.fps = cap.get(cv2.CAP_PROP_FPS) or 30.0
        self.width = int(cap.get(cv2.CAP_PROP_FRAME_WIDTH))
        self.height = int(cap.get(cv2.CAP_PROP_FRAME_HEIGHT))
        self.frame_count = int(cap.get(cv2.CAP_PROP_FRAME_COUNT))
        cap.release()

    def __iter__(self) -> Iterator[Frame]:
        cap = cv2.VideoCapture(str(self.path))
        index = 0
        try:
            while True:
                ok, image = cap.read()
                if not ok:
                    break
                yield Frame(index, index / self.fps, image)
                index += 1
        finally:
            cap.release()
```

```python
"""Choix des images à analyser et détection des images inchangées.

On compare des empreintes réduites (moyennes locales 8×8 environ) par différence maximale :
un petit texte qui apparaît modifie fortement quelques cellules, alors que le bruit
de compression s'annule dans les moyennes.
"""

from __future__ import annotations

import cv2
import numpy as np

TAILLE_EMPREINTE = (160, 90)


def empreinte(image: np.ndarray) -> np.ndarray:
    gris = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if image.ndim == 3 else image
    return cv2.resize(gris, TAILLE_EMPREINTE, interpolation=cv2.INTER_AREA).astype(np.int16)


def difference_max(a: np.ndarray, b: np.ndarray) -> int:
    return int(np.abs(a - b).max())


class Sampler:
    def __init__(self, video_fps: float, fps_analyse: float, diff_max: int, max_reutilisations: int):
        self.pas = max(1, round(video_fps / fps_analyse))
        self.diff_max = diff_max
        self.max_reutilisations = max_reutilisations
        self._reference: np.ndarray | None = None
        self._reutilisations = 0

    def is_sample(self, index: int) -> bool:
        return index % self.pas == 0

    def is_unchanged(self, image: np.ndarray) -> bool:
        courante = empreinte(image)
        if (
            self._reference is not None
            and self._reutilisations < self.max_reutilisations
            and difference_max(courante, self._reference) <= self.diff_max
        ):
            self._reutilisations += 1
            return True
        self._reference = courante
        self._reutilisations = 0
        return False
```

```python
"""Suivi des détections d'une analyse à l'autre et accumulation de l'OCR par piste."""

from __future__ import annotations

from collections import defaultdict
from dataclasses import dataclass, replace

import numpy as np
import supervision as sv
from trackers import ByteTrackTracker

from irl_guard.types import Box, Detection

TEXTE_MAX = 200
IOU_ADOPTION = 0.3


def fusionner_texte(cumul: str, nouveau: str, max_len: int = TEXTE_MAX) -> str:
    nouveau = nouveau.strip()
    if not cumul:
        return nouveau[:max_len]
    if not nouveau or nouveau.lower() in cumul.lower():
        return cumul
    if cumul.lower() in nouveau.lower():
        return nouveau[:max_len]
    return f"{cumul} | {nouveau}"[:max_len]


@dataclass
class Piste:
    id: int
    classe: str
    boite: Box
    conf: float
    texte: str | None = None
    nouveau: bool = True
    modifie: bool = True
    perdu: bool = False
    analyses_sans_detection: int = 0


def _vers_sv(detections: list[Detection]) -> sv.Detections:
    return sv.Detections(
        xyxy=np.array([d.boite.to_tuple() for d in detections], dtype=float),
        confidence=np.array([d.conf for d in detections], dtype=float),
        class_id=np.zeros(len(detections), dtype=int),
        data={"idx": np.arange(len(detections))},
    )


class TrackManager:
    """Un ByteTrack par classe, ids globaux stables, pistes perdues gardées `maintien` analyses."""

    def __init__(self, maintien: int):
        self.maintien = maintien
        self._trackers: dict[str, ByteTrackTracker] = {}
        self._ids: dict[tuple[str, int], int] = {}
        self._pistes: dict[int, Piste] = {}
        self._ephemeres: dict[str, list[int]] = defaultdict(list)
        self._prochain_id = 1

    def update(self, detections: list[Detection]) -> list[Piste]:
        par_classe: dict[str, list[Detection]] = defaultdict(list)
        for d in detections:
            par_classe[d.classe].append(d)

        vus: set[int] = set()
        ephemeres: dict[str, list[int]] = defaultdict(list)
        for classe in sorted(set(par_classe) | set(self._trackers)):
            dets = par_classe.get(classe, [])
            tracker = self._tracker(classe)
            if not dets:
                tracker.update(sv.Detections.empty())
                continue
            sortie = tracker.update(_vers_sv(dets))
            paires = list(zip(sortie.tracker_id.tolist(), sortie.data["idx"].tolist()))
            rendus = {idx for _, idx in paires}
            # Une détection non renvoyée par ByteTrack doit quand même être masquée.
            paires += [(-1, i) for i in range(len(dets)) if i not in rendus]
            for tracker_id, idx in paires:
                det = dets[idx]
                if tracker_id < 0:
                    pid = self._adopter(classe, det.boite, vus) or self._nouvel_id()
                    ephemeres[classe].append(pid)
                else:
                    cle = (classe, tracker_id)
                    if cle not in self._ids:
                        self._ids[cle] = self._adopter(classe, det.boite, vus) or self._nouvel_id()
                    pid = self._ids[cle]
                self._mettre_a_jour(pid, det)
                vus.add(pid)

        self._ephemeres = ephemeres
        self._vieillir(vus)
        return [replace(p) for p in self._pistes.values()]

    def _tracker(self, classe: str) -> ByteTrackTracker:
        if classe not in self._trackers:
            # frame_rate=30 : lost_track_buffer s'exprime alors directement en nombre d'analyses.
            self._trackers[classe] = ByteTrackTracker(
                lost_track_buffer=max(1, self.maintien),
                frame_rate=30.0,
                track_activation_threshold=0.25,
                minimum_consecutive_frames=1,
                high_conf_det_threshold=0.25,
            )
        return self._trackers[classe]

    def _nouvel_id(self) -> int:
        pid = self._prochain_id
        self._prochain_id += 1
        return pid

    def _adopter(self, classe: str, boite: Box, deja_pris: set[int]) -> int | None:
        """Reprend l'id d'une piste éphémère de l'analyse précédente située au même endroit."""
        meilleur, meilleur_iou = None, IOU_ADOPTION
        for pid in self._ephemeres[classe]:
            piste = self._pistes.get(pid)
            if piste is None or pid in deja_pris:
                continue
            iou = piste.boite.iou(boite)
            if iou >= meilleur_iou:
                meilleur, meilleur_iou = pid, iou
        return meilleur

    def _mettre_a_jour(self, pid: int, det: Detection) -> None:
        texte = det.texte.strip() if det.texte else None
        piste = self._pistes.get(pid)
        if piste is None:
            self._pistes[pid] = Piste(pid, det.classe, det.boite, det.conf, texte=texte or None)
            return
        ancien = piste.texte
        if texte:
            piste.texte = fusionner_texte(piste.texte or "", texte)
        piste.boite, piste.conf = det.boite, det.conf
        piste.nouveau, piste.modifie = False, piste.texte != ancien
        piste.perdu, piste.analyses_sans_detection = False, 0

    def _vieillir(self, vus: set[int]) -> None:
        for pid in list(self._pistes):
            if pid in vus:
                continue
            piste = self._pistes[pid]
            piste.analyses_sans_detection += 1
            piste.perdu, piste.nouveau, piste.modifie = True, False, False
            if piste.analyses_sans_detection > self.maintien:
                del self._pistes[pid]
```

```python
"""Construction du `state` JSON envoyé au décideur pour une piste."""

from __future__ import annotations

import json
from collections import Counter

from irl_guard.config import SessionConfig, TailleConfig
from irl_guard.tracking import Piste
from irl_guard.types import Box

CONTEXTE_TEXTE_MAX = 40


def taille_relative(boite: Box, largeur: int, hauteur: int, cfg: TailleConfig) -> str:
    part = boite.area / float(largeur * hauteur)
    if part <= cfg.petite_max:
        return "petite"
    if part <= cfg.moyenne_max:
        return "moyenne"
    return "grande"


def resume_contexte(cible: Piste, pistes: list[Piste]) -> list[str]:
    autres = [p for p in pistes if p.id != cible.id and not p.perdu]
    comptes = Counter(p.classe for p in autres if p.classe != "texte")
    resume = [f"{classe} x{n}" for classe, n in sorted(comptes.items())]
    resume += [f"texte: {p.texte[:CONTEXTE_TEXTE_MAX]}" for p in autres if p.classe == "texte" and p.texte]
    return resume


def estimer_tokens(obj) -> int:
    """Estimation prudente, faute du tokenizer exact de Laya : environ 3 caractères par token."""
    return len(json.dumps(obj, ensure_ascii=False)) // 3 + 1


def construire_state(cible: Piste, pistes: list[Piste], cfg: SessionConfig, largeur: int, hauteur: int) -> dict:
    description: dict = {"type": "texte" if cible.classe == "texte" else "objet"}
    if cible.classe != "texte":
        description["classe"] = cible.classe
    if cible.texte:
        description["texte"] = cible.texte
    description["conf"] = round(cible.conf, 2)
    description["taille"] = taille_relative(cible.boite, largeur, hauteur, cfg.taille)

    state = {
        "categorie": cfg.categorie,
        "mode_domicile": cfg.mode_domicile,
        "charte": cfg.charte,
        "cible": description,
        "contexte": resume_contexte(cible, pistes),
    }
    # Seul le contexte est tronqué : la cible et la charte ne le sont jamais.
    while estimer_tokens(state) > cfg.budget_tokens_state and state["contexte"]:
        state["contexte"].pop()
    return state
```

```python
from dataclasses import dataclass, field
from typing import Protocol

ACTIONS = ("diffuser", "flouter", "pause")
RISQUES = ("localisation", "donnee_perso", "arme", "propos", "aucun")
NIVEAUX_GRAVITE = ("aucune", "faible", "élevée", "critique")

QUESTIONS = {
    "action": {
        "type": "choice",
        "instructions": "Que faire de cet élément dans le live ?",
        "criteria": {
            "diffuser": "rien de problématique",
            "flouter": "problème localisé et masquable",
            "pause": "problème grave ou impossible à masquer",
        },
    },
    "risque": {
        "type": "choice",
        "instructions": "Quel est le risque principal ?",
        "criteria": {
            "localisation": "nom de rue, numéro, enseigne, repère identifiable",
            "donnee_perso": "document, écran, nom, adresse, e-mail",
            "arme": "arme réelle ou objet menaçant",
            "propos": "texte injurieux ou haineux",
            "aucun": "aucun risque",
        },
    },
    "gravite": {
        "type": "score",
        "instructions": "Quelle est la gravité ?",
        "criteria": list(NIVEAUX_GRAVITE),
    },
}


@dataclass(frozen=True)
class Decision:
    action: str
    risque: str
    gravite: int
    probabilites: dict[str, dict[str, float]] = field(default_factory=dict)
    source: str = "rules"

    @property
    def p_pause(self) -> float:
        p = self.probabilites.get("action", {})
        if "pause" in p:
            return float(p["pause"])
        return 1.0 if self.action == "pause" else 0.0

    def to_dict(self) -> dict:
        return {"action": self.action, "risque": self.risque, "gravite": self.gravite,
                "probabilites": self.probabilites, "source": self.source}


def action_depuis_probas(p: dict[str, float], seuil_pause: float, seuil_flou: float) -> str:
    """Biais vers la protection : flouter dès que flouter + pause dépasse le seuil."""
    if p["pause"] >= seuil_pause:
        return "pause"
    if p["flouter"] + p["pause"] >= seuil_flou:
        return "flouter"
    return "diffuser"


def decision_repli() -> Decision:
    """Décision appliquée quand le décideur échoue : on masque."""
    return Decision("flouter", "inconnu", 2, {}, "fallback")


class Decider(Protocol):
    def decide(self, state: dict) -> Decision: ...
```

```python
"""Décideur à base de règles : plancher de référence et repli quand Laya n'est pas utilisé."""

from __future__ import annotations

import re
import unicodedata

from irl_guard.config import SessionConfig
from irl_guard.decision.base import ACTIONS, Decision

VOIE = re.compile(r"\b(rue|avenue|av|boulevard|bd|place|chemin|impasse|allee|quai|route|square"
                  r"|cours|passage|residence|lotissement)\b")
NUMERO = re.compile(r"^\s*\d{1,4}\s*(bis|ter)?\s*$")
CODE_POSTAL = re.compile(r"\b\d{5}\b")
EMAIL = re.compile(r"[\w.+-]+@[\w-]+\.[\w.]+")
TELEPHONE = re.compile(r"(\+33\s?|\b0)[1-9]([\s.-]?\d{2}){4}\b")
MOTS_OFFENSANTS_BASE = ("connard", "connasse", "salope", "salaud", "encule", "pute", "batard", "fdp", "ntm")


def normaliser(texte: str) -> str:
    sans_accents = unicodedata.normalize("NFKD", texte).encode("ascii", "ignore").decode()
    return sans_accents.lower()


class RulesDecider:
    def __init__(self, cfg: SessionConfig):
        mots = [normaliser(m) for m in (*MOTS_OFFENSANTS_BASE, *cfg.regles.mots_offensants)]
        self._offensant = re.compile(r"\b(" + "|".join(re.escape(m) for m in mots) + r")\b")
        self._categories_couteau_ok = {c.lower() for c in cfg.regles.categories_couteau_ok}

    def decide(self, state: dict) -> Decision:
        cible = state["cible"]
        if cible["type"] == "texte":
            return self._texte(normaliser(cible.get("texte") or ""), state, cible.get("taille", "petite"))
        if cible.get("classe") in ("couteau", "ciseaux"):
            if str(state.get("categorie", "")).lower() in self._categories_couteau_ok:
                return self._d("diffuser", "aucun", 0)
            return self._d("flouter", "arme", 2)
        return self._d("diffuser", "aucun", 0)

    def _texte(self, texte: str, state: dict, taille: str) -> Decision:
        if self._offensant.search(texte):
            return self._d("flouter", "propos", 2)
        if EMAIL.search(texte) or TELEPHONE.search(texte):
            return self._d("flouter", "donnee_perso", 2)
        if VOIE.search(texte) or NUMERO.match(texte) or CODE_POSTAL.search(texte):
            if state.get("mode_domicile") and taille != "petite":
                return self._d("pause", "localisation", 3)
            return self._d("flouter", "localisation", 2)
        return self._d("diffuser", "aucun", 0)

    @staticmethod
    def _d(action: str, risque: str, gravite: int) -> Decision:
        probas = {a: 1.0 if a == action else 0.0 for a in ACTIONS}
        return Decision(action, risque, gravite, {"action": probas}, "rules")
```

```python
"""Client de la Decision API d'Unsloth (Laya ou modèle fine-tuné servi par Unsloth Studio)."""

from __future__ import annotations

import logging

import httpx

from irl_guard.config import SessionConfig
from irl_guard.decision.base import (
    ACTIONS, NIVEAUX_GRAVITE, QUESTIONS, RISQUES, Decision, action_depuis_probas, decision_repli,
)

log = logging.getLogger(__name__)
ERREURS_REPONSE = (KeyError, ValueError, TypeError)


class LayaIndisponible(RuntimeError):
    pass


def _probas(reponse: dict, options: tuple[str, ...]) -> dict[str, float]:
    brutes = reponse["probabilities"]
    probas = {o: float(brutes[o]) for o in options}
    if any(not 0.0 <= v <= 1.0 for v in probas.values()):
        raise ValueError(f"probabilité hors de [0, 1] : {probas}")
    return probas


def _gravite(reponse: dict) -> int:
    score = reponse["score"]
    if isinstance(score, str) and score in NIVEAUX_GRAVITE:
        return NIVEAUX_GRAVITE.index(score)
    if isinstance(score, (int, float)) and not isinstance(score, bool):
        return min(max(int(score), 0), len(NIVEAUX_GRAVITE) - 1)
    raise ValueError(f"score de gravité inattendu : {score!r}")


def parser_reponse(data: dict, seuil_pause: float, seuil_flou: float) -> Decision:
    reponses = data["answers"]
    p_action = _probas(reponses["action"], ACTIONS)
    p_risque = _probas(reponses["risque"], RISQUES)
    return Decision(
        action=action_depuis_probas(p_action, seuil_pause, seuil_flou),
        risque=max(p_risque, key=p_risque.get),
        gravite=_gravite(reponses["gravite"]),
        probabilites={"action": p_action, "risque": p_risque},
        source="laya",
    )


class LayaDecider:
    def __init__(self, cfg: SessionConfig, transport: httpx.BaseTransport | None = None):
        self.cfg = cfg
        laya = cfg.laya
        en_tetes = {"Authorization": f"Bearer {laya.cle}"} if laya.cle else {}
        self._client = httpx.Client(base_url=laya.url, timeout=laya.timeout_s,
                                    headers=en_tetes, transport=transport)

    def _appeler(self, state: dict) -> Decision:
        corps = {"model": self.cfg.laya.modele, "state": state, "questions": QUESTIONS}
        reponse = self._client.post("/v1/systemone", json=corps)
        reponse.raise_for_status()
        return parser_reponse(reponse.json(), self.cfg.seuils.pause, self.cfg.seuils.flou)

    def decide(self, state: dict) -> Decision:
        try:
            return self._appeler(state)
        except (httpx.HTTPError, *ERREURS_REPONSE) as e:
            log.warning("Décision Laya impossible, piste floutée par défaut : %s", e)
            return decision_repli()

    def verifier(self) -> None:
        try:
            self._appeler({"cible": {"type": "texte", "texte": "test"}})
        except (httpx.HTTPError, *ERREURS_REPONSE) as e:
            raise LayaIndisponible(
                f"Laya injoignable ou réponse invalide sur {self.cfg.laya.url} : {e}. "
                "Lance l'app Unsloth et active Settings → API → Decision API, "
                "ou relance avec --decider rules."
            ) from e
```

```python
"""Hystérésis de la pause : entrée immédiate, sortie après K analyses calmes."""

from __future__ import annotations


class Hysteresis:
    def __init__(self, haut: float, bas: float, k: int):
        self.haut, self.bas, self.k = haut, bas, k
        self.en_pause = False
        self._calmes = 0

    def update(self, score: float) -> bool:
        if score >= self.haut:
            self.en_pause, self._calmes = True, 0
        elif self.en_pause:
            if score < self.bas:
                self._calmes += 1
                if self._calmes >= self.k:
                    self.en_pause, self._calmes = False, 0
            else:
                self._calmes = 0
        return self.en_pause
```

```python
"""Analyse d'une image échantillonnée : suivi, décisions par piste, score et hystérésis."""

from __future__ import annotations

from dataclasses import dataclass

from irl_guard.config import SessionConfig
from irl_guard.decision.base import Decider, Decision
from irl_guard.state import construire_state
from irl_guard.temporal import Hysteresis
from irl_guard.tracking import Piste, TrackManager
from irl_guard.types import CLASSE_NUDITE, CLASSES_CONTEXTE, CLASSES_REGLE, Box, Detection


@dataclass(frozen=True)
class PisteAnalysee:
    id: int
    classe: str
    boite: Box
    texte: str | None
    action: str
    perdu: bool
    decision: Decision | None = None

    @property
    def masquer(self) -> bool:
        return self.action in ("flouter", "pause")

    def to_dict(self) -> dict:
        return {"id": self.id, "classe": self.classe, "boite": self.boite.to_list(), "texte": self.texte,
                "action": self.action, "perdu": self.perdu,
                "decision": self.decision.to_dict() if self.decision else None}


@dataclass(frozen=True)
class Analyse:
    frame_index: int
    pistes: tuple[PisteAnalysee, ...]
    score: float
    en_pause: bool
    appels: tuple[dict, ...] = ()
    reutilisee: bool = False

    def to_dict(self) -> dict:
        return {"frame": self.frame_index, "score": round(self.score, 4), "en_pause": self.en_pause,
                "reutilisee": self.reutilisee, "pistes": [p.to_dict() for p in self.pistes],
                "appels": list(self.appels)}


class Analyzer:
    def __init__(self, cfg: SessionConfig, decider: Decider, largeur: int, hauteur: int):
        self.cfg, self.decider = cfg, decider
        self.largeur, self.hauteur = largeur, hauteur
        self.pistes = TrackManager(maintien=cfg.maintien)
        self.hysteresis = Hysteresis(cfg.seuils.hysteresis_haut, cfg.seuils.hysteresis_bas, cfg.seuils.sortie_k)
        self._cache: dict[tuple[int, str | None], Decision] = {}

    def analyser(self, frame_index: int, detections: list[Detection]) -> Analyse:
        pistes = self.pistes.update(detections)
        score = 0.0
        appels: list[dict] = []
        resultats: list[PisteAnalysee] = []
        for p in pistes:
            decision = None
            if p.classe == CLASSE_NUDITE:
                action = "flouter"
                if not p.perdu and p.conf >= self.cfg.seuils.nudite:
                    score = 1.0
            elif p.classe in CLASSES_REGLE:
                action = "flouter"
            elif p.classe in CLASSES_CONTEXTE:
                decision = self._decision(p, pistes, appels)
                action = decision.action
                score = max(score, decision.p_pause)
            else:
                action = "diffuser"
            resultats.append(PisteAnalysee(p.id, p.classe, p.boite, p.texte, action, p.perdu, decision))
        en_pause = self.hysteresis.update(score)
        return Analyse(frame_index, tuple(resultats), score, en_pause, tuple(appels))

    def _decision(self, piste: Piste, pistes: list[Piste], appels: list[dict]) -> Decision:
        cle = (piste.id, piste.texte)
        if cle in self._cache:
            return self._cache[cle]
        state = construire_state(piste, pistes, self.cfg, self.largeur, self.hauteur)
        decision = self.decider.decide(state)
        appels.append({"piste": piste.id, "state": state, "decision": decision.to_dict()})
        if decision.source != "fallback":
            self._cache[cle] = decision
        return decision
```

```python
"""Plan de rendu d'une image à partir des analyses qui l'encadrent (le tampon donne l'analyse suivante)."""

from __future__ import annotations

from dataclasses import dataclass

from irl_guard.analysis import Analyse
from irl_guard.types import Box


@dataclass(frozen=True)
class PlanImage:
    masques: tuple[Box, ...]
    pause: bool
    analyse: Analyse | None = None


def _boites_masquees(analyse: Analyse | None) -> dict[int, Box]:
    if analyse is None:
        return {}
    return {p.id: p.boite for p in analyse.pistes if p.masquer}


def planifier(frame_index: int, avant: Analyse | None, apres: Analyse | None,
              marge: float, largeur: int, hauteur: int) -> PlanImage:
    if avant is not None and avant.frame_index == frame_index:
        apres = None
    if avant is None and apres is None:
        return PlanImage((), False, None)

    a, b = _boites_masquees(avant), _boites_masquees(apres)
    t = 0.0
    if avant is not None and apres is not None:
        t = (frame_index - avant.frame_index) / (apres.frame_index - avant.frame_index)

    masques = []
    for pid in sorted(a.keys() | b.keys()):
        if pid in a and pid in b:
            boite = a[pid].lerp(b[pid], t)
        else:
            boite = a[pid] if pid in a else b[pid]
        masques.append(boite.expand(marge, largeur, hauteur))

    pause = bool((avant is not None and avant.en_pause) or (apres is not None and apres.en_pause))
    return PlanImage(tuple(masques), pause, avant if avant is not None else apres)
```

```python
"""Rendu d'une image : masquage par zone, écran de pause, overlay de debug."""

from __future__ import annotations

import math
from pathlib import Path

import cv2
import numpy as np

from irl_guard.analysis import Analyse
from irl_guard.planning import PlanImage
from irl_guard.types import Box

POLICE = cv2.FONT_HERSHEY_SIMPLEX
COULEURS = {"diffuser": (0, 180, 0), "flouter": (0, 140, 255), "pause": (0, 0, 255)}


def masquer(image: np.ndarray, boite: Box, mode: str) -> None:
    h, w = image.shape[:2]
    x1, y1 = max(0, int(boite.x1)), max(0, int(boite.y1))
    x2, y2 = min(w, math.ceil(boite.x2)), min(h, math.ceil(boite.y2))
    if x2 <= x1 or y2 <= y1:
        return
    roi = image[y1:y2, x1:x2]
    rw, rh = x2 - x1, y2 - y1
    if mode == "pixel":
        # Au plus une dizaine de blocs sur le grand côté : aucun caractère ne reste lisible.
        bloc = max(8, max(rw, rh) // 10)
        petit = cv2.resize(roi, (max(1, rw // bloc), max(1, rh // bloc)), interpolation=cv2.INTER_AREA)
        roi[:] = cv2.resize(petit, (rw, rh), interpolation=cv2.INTER_NEAREST)
    else:
        k = max(31, (max(rw, rh) // 2) | 1)
        roi[:] = cv2.GaussianBlur(roi, (k, k), 0)


def ecran_pause(largeur: int, hauteur: int, chemin: Path | None = None) -> np.ndarray:
    if chemin is not None:
        image = cv2.imread(str(chemin))
        if image is None:
            raise FileNotFoundError(f"Écran de pause introuvable : {chemin}")
        return cv2.resize(image, (largeur, hauteur))
    image = np.full((hauteur, largeur, 3), 30, np.uint8)
    texte = "Pause de securite"
    echelle = max(0.5, largeur / 800)
    (tw, th), _ = cv2.getTextSize(texte, POLICE, echelle, 2)
    cv2.putText(image, texte, ((largeur - tw) // 2, (hauteur + th) // 2), POLICE, echelle,
                (255, 255, 255), 2, cv2.LINE_AA)
    return image


def dessiner_overlay(image: np.ndarray, analyse: Analyse, en_pause: bool) -> None:
    for p in analyse.pistes:
        x1, y1, x2, y2 = (int(v) for v in p.boite.to_tuple())
        couleur = COULEURS.get(p.action, (200, 200, 200))
        cv2.rectangle(image, (x1, y1), (x2, y2), couleur, 2)
        etiquette = f"#{p.id} {p.classe} {p.action}"
        if p.decision is not None:
            etiquette += f" P(pause)={p.decision.p_pause:.2f}"
        if p.texte:
            etiquette += f" '{p.texte[:30]}'"
        cv2.putText(image, etiquette, (x1, max(12, y1 - 4)), POLICE, 0.45, couleur, 1, cv2.LINE_AA)
    etat = "PAUSE" if en_pause else "DIFFUSION"
    bandeau = f"{etat}  score={analyse.score:.2f}  analyse #{analyse.frame_index}"
    cv2.putText(image, bandeau, (8, 20), POLICE, 0.6, COULEURS["pause" if en_pause else "diffuser"], 2, cv2.LINE_AA)


def rendre(image: np.ndarray, plan: PlanImage, masquage: str, ecran: np.ndarray, debug: bool = False) -> np.ndarray:
    if plan.pause:
        sortie = ecran.copy()
    else:
        sortie = image.copy()
        for boite in plan.masques:
            masquer(sortie, boite, masquage)
    if debug and plan.analyse is not None:
        dessiner_overlay(sortie, plan.analyse, plan.pause)
    return sortie
```

```python
"""Journal JSONL : une ligne par image analysée. Il sert au débogage et au rejeu sans perception."""

from __future__ import annotations

import json
from pathlib import Path

from irl_guard.analysis import Analyse
from irl_guard.types import Detection


class Journal:
    def __init__(self, chemin: str | Path):
        self.chemin = Path(chemin)
        self._fichier = None

    def __enter__(self) -> Journal:
        self.chemin.parent.mkdir(parents=True, exist_ok=True)
        self._fichier = self.chemin.open("w", encoding="utf-8")
        return self

    def __exit__(self, *exc) -> None:
        self._fichier.close()

    def ecrire(self, analyse: Analyse, detections: list[Detection]) -> None:
        ligne = {"frame": analyse.frame_index,
                 "detections": [d.to_dict() for d in detections],
                 "analyse": analyse.to_dict()}
        self._fichier.write(json.dumps(ligne, ensure_ascii=False) + "\n")


def lire_detections(chemin: str | Path) -> dict[int, list[Detection]]:
    resultat: dict[int, list[Detection]] = {}
    with Path(chemin).open(encoding="utf-8") as f:
        for ligne in f:
            if ligne.strip():
                d = json.loads(ligne)
                resultat[int(d["frame"])] = [Detection.from_dict(x) for x in d["detections"]]
    return resultat
```

```python
"""Finalisation vidéo avec le binaire ffmpeg fourni par imageio-ffmpeg."""

from __future__ import annotations

import logging
import subprocess
from pathlib import Path

import imageio_ffmpeg

log = logging.getLogger(__name__)


def ffmpeg_exe() -> str:
    return imageio_ffmpeg.get_ffmpeg_exe()


def a_une_piste_audio(chemin: str | Path) -> bool:
    r = subprocess.run([ffmpeg_exe(), "-hide_banner", "-i", str(chemin)],
                       capture_output=True, text=True, encoding="utf-8", errors="replace")
    return "Audio:" in r.stderr


def intervalles_pause(drapeaux: list[bool], fps: float) -> list[tuple[float, float]]:
    intervalles, debut = [], None
    for i, pause in enumerate([*drapeaux, False]):
        if pause and debut is None:
            debut = i
        elif not pause and debut is not None:
            intervalles.append((round(debut / fps, 3), round(i / fps, 3)))
            debut = None
    return intervalles


def finaliser(video_muette: str | Path, source: str | Path, sortie: str | Path,
              intervalles: list[tuple[float, float]], couper_audio: bool) -> None:
    cmd = [ffmpeg_exe(), "-y", "-hide_banner", "-loglevel", "error", "-i", str(video_muette)]
    if a_une_piste_audio(source):
        cmd += ["-i", str(source), "-map", "0:v:0", "-map", "1:a:0", "-c:a", "aac", "-shortest"]
        if couper_audio and intervalles:
            expr = "+".join(f"between(t,{a:.3f},{b:.3f})" for a, b in intervalles)
            cmd += ["-af", f"volume=enable='{expr}':volume=0"]
    else:
        log.warning("Vidéo source sans piste audio : sortie sans audio (%s)", source)
    cmd += ["-c:v", "libx264", "-pix_fmt", "yuv420p", "-preset", "veryfast", str(sortie)]
    subprocess.run(cmd, check=True)
```

```python
"""Interfaces de perception, composition de détecteurs et rejeu depuis le journal."""

from __future__ import annotations

from typing import Protocol

import numpy as np

from irl_guard.types import Detection


class DetecteurIndisponible(RuntimeError):
    pass


class JournalIncompatible(RuntimeError):
    pass


class Detector(Protocol):
    def detect(self, image: np.ndarray) -> list[Detection]: ...


class Perception:
    def __init__(self, detecteurs: list[Detector]):
        self.detecteurs = detecteurs

    def detect(self, frame_index: int, image: np.ndarray) -> list[Detection]:
        return [d for detecteur in self.detecteurs for d in detecteur.detect(image)]


class CachedPerception:
    def __init__(self, cache: dict[int, list[Detection]]):
        self.cache = cache

    def detect(self, frame_index: int, image: np.ndarray) -> list[Detection]:
        if frame_index not in self.cache:
            raise JournalIncompatible(
                f"L'image {frame_index} n'est pas dans le journal : "
                "rejoue avec le même fps_analyse que l'analyse d'origine.")
        return self.cache[frame_index]
```

```python
"""Détecteurs Ultralytics YOLO : objets COCO, visages et plaques."""

from __future__ import annotations

import numpy as np

from irl_guard.config import PoidsHF
from irl_guard.types import Box, Detection

COCO_VERS_CLASSES = {
    "person": "personne", "knife": "couteau", "scissors": "ciseaux", "car": "voiture",
    "motorcycle": "moto", "bus": "bus", "truck": "camion", "cell phone": "telephone",
    "laptop": "ordinateur", "stop sign": "panneau_stop",
}


def poids_hf(p: PoidsHF) -> str:
    from huggingface_hub import hf_hub_download
    return hf_hub_download(p.repo, p.fichier)


class YoloDetector:
    """`correspondance` traduit les noms du modèle ; la clé "*" s'applique à toutes les classes."""

    def __init__(self, poids: str, correspondance: dict[str, str], conf_min: float, device: str | None):
        from ultralytics import YOLO
        self.modele = YOLO(poids)
        self.correspondance = correspondance
        self.conf_min = conf_min
        self.device = device

    def detect(self, image: np.ndarray) -> list[Detection]:
        r = self.modele.predict(image, conf=self.conf_min, device=self.device, verbose=False)[0]
        detections = []
        for (x1, y1, x2, y2), conf, k in zip(r.boxes.xyxy.tolist(), r.boxes.conf.tolist(), r.boxes.cls.tolist()):
            nom = r.names[int(k)]
            classe = self.correspondance.get(nom, self.correspondance.get("*"))
            if classe:
                detections.append(Detection(classe, float(conf), Box(x1, y1, x2, y2)))
        return detections
```

```python
CLASSES_EXPOSEES = frozenset({
    "FEMALE_GENITALIA_EXPOSED", "FEMALE_BREAST_EXPOSED", "MALE_GENITALIA_EXPOSED",
    "BUTTOCKS_EXPOSED", "ANUS_EXPOSED",
})


class NudityDetector:
    def __init__(self, conf_min: float):
        from nudenet import NudeDetector
        self.modele = NudeDetector()
        self.conf_min = conf_min

    def detect(self, image: np.ndarray) -> list[Detection]:
        detections = []
        for d in self.modele.detect(image):
            if d["class"] in CLASSES_EXPOSEES and d["score"] >= self.conf_min:
                x, y, w, h = d["box"]
                detections.append(Detection(CLASSE_NUDITE, float(d["score"]), Box(x, y, x + w, y + h)))
        return detections
```

```python
"""Lecture du texte visible avec RapidOCR (modèles PaddleOCR en ONNX, CPU)."""

from __future__ import annotations

import numpy as np

from irl_guard.types import Box, Detection


class TextDetector:
    def __init__(self, conf_min: float):
        from rapidocr import RapidOCR
        self.moteur = RapidOCR(params={"Global.log_level": "critical"})
        self.conf_min = conf_min

    def detect(self, image: np.ndarray) -> list[Detection]:
        r = self.moteur(image)
        if r.boxes is None or r.txts is None:
            return []
        detections = []
        for quad, texte, score in zip(r.boxes, r.txts, r.scores):
            if score < self.conf_min or not texte.strip():
                continue
            xs, ys = quad[:, 0], quad[:, 1]
            boite = Box(float(xs.min()), float(ys.min()), float(xs.max()), float(ys.max()))
            detections.append(Detection("texte", float(score), boite, texte.strip()))
        return detections
```

```python
    try:
        return fabrique()
```

```python
"""Pipeline hors ligne en deux passes : analyse des images échantillonnées, puis rendu de toutes les images."""

from __future__ import annotations

import bisect
import tempfile
import time
from dataclasses import dataclass, replace
from pathlib import Path

import cv2

from irl_guard.analysis import Analyse, Analyzer
from irl_guard.config import SessionConfig
from irl_guard.decision.base import Decider
from irl_guard.journal import Journal
from irl_guard.media import finaliser, intervalles_pause
from irl_guard.planning import planifier
from irl_guard.render import ecran_pause, rendre
from irl_guard.sampling import Sampler
from irl_guard.sources import VideoSource


@dataclass(frozen=True)
class Resultat:
    sortie: Path
    sortie_debug: Path | None
    journal: Path
    images: int
    analyses: int
    duree_video_s: float
    duree_traitement_s: float

    @property
    def debit(self) -> float:
        """Multiple du temps réel : 2.0 = deux fois plus rapide que la lecture."""
        if self.duree_traitement_s <= 0:
            return float("inf")
        return self.duree_video_s / self.duree_traitement_s


def analyser_video(source: VideoSource, perception, analyzer: Analyzer, sampler: Sampler,
                   journal: Journal) -> list[Analyse]:
    analyses: list[Analyse] = []
    derniere, detections_derniere = None, []
    for frame in source:
        if not sampler.is_sample(frame.index):
            continue
        inchangee = sampler.is_unchanged(frame.image)
        if inchangee and derniere is not None:
            analyse = replace(derniere, frame_index=frame.index, appels=(), reutilisee=True)
            detections = detections_derniere
        else:
            detections = perception.detect(frame.index, frame.image)
            analyse = analyzer.analyser(frame.index, detections)
        journal.ecrire(analyse, detections)
        analyses.append(analyse)
        derniere, detections_derniere = analyse, detections
    return analyses


def rendre_video(source: VideoSource, analyses: list[Analyse], cfg: SessionConfig,
                 sorties: list[tuple[Path, bool]]) -> list[bool]:
    indices = [a.frame_index for a in analyses]
    ecran = ecran_pause(source.width, source.height, cfg.ecran_pause)
    fourcc = cv2.VideoWriter_fourcc(*"mp4v")
    writers = [(cv2.VideoWriter(str(p), fourcc, source.fps, (source.width, source.height)), debug)
               for p, debug in sorties]
    pauses: list[bool] = []
    try:
        for frame in source:
            k = bisect.bisect_right(indices, frame.index)
            avant = analyses[k - 1] if k > 0 else None
            apres = analyses[k] if k < len(analyses) else None
            plan = planifier(frame.index, avant, apres, cfg.marge, source.width, source.height)
            pauses.append(plan.pause)
            for writer, debug in writers:
                writer.write(rendre(frame.image, plan, cfg.masquage, ecran, debug))
    finally:
        for writer, _ in writers:
            writer.release()
    return pauses


def chemin_debug(sortie: Path) -> Path:
    return sortie.with_name(f"{sortie.stem}_debug{sortie.suffix}")


def traiter_video(entree: str | Path, sortie: str | Path, cfg: SessionConfig, perception, decider: Decider,
                  debug: bool = False, journal: str | Path | None = None) -> Resultat:
    entree, sortie = Path(entree), Path(sortie)
    sortie.parent.mkdir(parents=True, exist_ok=True)
    chemin_journal = Path(journal) if journal else sortie.with_suffix(".jsonl")
    source = VideoSource(entree)
    sampler = Sampler(source.fps, cfg.fps_analyse, cfg.seuils.diff_max, cfg.seuils.max_reutilisations)
    analyzer = Analyzer(cfg, decider, source.width, source.height)

    debut = time.perf_counter()
    with Journal(chemin_journal) as j:
        analyses = analyser_video(source, perception, analyzer, sampler, j)

    sortie_debug = chemin_debug(sortie) if debug else None
    with tempfile.TemporaryDirectory() as tmp:
        muettes = [(Path(tmp) / "protegee.mp4", False)]
        if debug:
            muettes.append((Path(tmp) / "debug.mp4", True))
        pauses = rendre_video(source, analyses, cfg, muettes)
        intervalles = intervalles_pause(pauses, source.fps)
        finaliser(muettes[0][0], entree, sortie, intervalles, cfg.couper_audio_en_pause)
        if debug:
            finaliser(muettes[1][0], entree, sortie_debug, intervalles, cfg.couper_audio_en_pause)

    return Resultat(sortie, sortie_debug, chemin_journal, len(pauses), len(analyses),
                    len(pauses) / source.fps, time.perf_counter() - debut)
```

```python
"""Ligne de commande : `irl-guard process` et `irl-guard replay`."""

from __future__ import annotations

from collections.abc import Callable
from enum import Enum
from pathlib import Path

import typer

from irl_guard.config import SessionConfig, load_config
from irl_guard.decision.base import Decider
from irl_guard.decision.laya import LayaDecider, LayaIndisponible
from irl_guard.decision.rules import RulesDecider
from irl_guard.journal import lire_detections
from irl_guard.perception.base import CachedPerception, DetecteurIndisponible, JournalIncompatible
from irl_guard.perception.factory import construire_perception
from irl_guard.pipeline import traiter_video

app = typer.Typer(add_completion=False, help="Bloqueur de contenu pour lives IRL (V1 hors ligne).")


class ChoixDecider(str, Enum):
    laya = "laya"
    rules = "rules"


def creer_decider(choix: ChoixDecider, cfg: SessionConfig) -> Decider:
    if choix == ChoixDecider.rules:
        return RulesDecider(cfg)
    decider = LayaDecider(cfg)
    decider.verifier()
    return decider


def _executer(entree: Path, out: Path, config: Path, debug_overlay: bool, choix: ChoixDecider,
              fabrique_perception: Callable[[SessionConfig], object]) -> None:
    cfg = load_config(config)
    try:
        decider = creer_decider(choix, cfg)
    except LayaIndisponible as e:
        typer.echo(str(e), err=True)
        raise typer.Exit(2)
    try:
        perception = fabrique_perception(cfg)
    except DetecteurIndisponible as e:
        typer.echo(str(e), err=True)
        raise typer.Exit(3)
    try:
        res = traiter_video(entree, out, cfg, perception, decider, debug=debug_overlay)
    except JournalIncompatible as e:
        typer.echo(str(e), err=True)
        raise typer.Exit(4)
    typer.echo(f"Vidéo protégée : {res.sortie}")
    if res.sortie_debug:
        typer.echo(f"Vidéo de debug : {res.sortie_debug}")
    typer.echo(f"Journal : {res.journal}")
    typer.echo(f"{res.images} images, {res.analyses} analyses, {res.duree_traitement_s:.1f} s "
               f"— débit {res.debit:.2f}x temps réel")


@app.command()
def process(
    entree: Path = typer.Argument(..., exists=True, dir_okay=False, help="Vidéo à protéger"),
    config: Path = typer.Option(..., "--config", exists=True, dir_okay=False, help="YAML de session"),
    out: Path = typer.Option(..., "--out", help="Vidéo protégée en sortie"),
    debug_overlay: bool = typer.Option(False, "--debug-overlay", help="Produit aussi <out>_debug.mp4"),
    decider: ChoixDecider = typer.Option(ChoixDecider.laya, "--decider"),
) -> None:
    """Analyse une vidéo et produit sa version protégée."""
    _executer(entree, out, config, debug_overlay, decider, construire_perception)


@app.command()
def replay(
    journal: Path = typer.Argument(..., exists=True, dir_okay=False, help="Journal JSONL d'une analyse"),
    entree: Path = typer.Argument(..., exists=True, dir_okay=False, help="Vidéo d'origine"),
    config: Path = typer.Option(..., "--config", exists=True, dir_okay=False),
    out: Path = typer.Option(..., "--out"),
    debug_overlay: bool = typer.Option(False, "--debug-overlay"),
    decider: ChoixDecider = typer.Option(ChoixDecider.laya, "--decider"),
) -> None:
    """Rejoue une analyse avec d'autres réglages, sans refaire la perception."""
    if out.with_suffix(".jsonl").resolve() == journal.resolve():
        typer.echo("La sortie écraserait le journal source : choisis un autre --out.", err=True)
        raise typer.Exit(1)
    cache = lire_detections(journal)
    _executer(entree, out, config, debug_overlay, decider, lambda cfg: CachedPerception(cache))
```

```python
"""Critère de réussite V1 n° 2 : aucune image de sortie ne laisse relire le texte sensible."""

import cv2
import pytest

from irl_guard.config import SessionConfig
from irl_guard.decision.rules import RulesDecider
from irl_guard.perception.base import Perception
from irl_guard.perception.text import TextDetector
from irl_guard.pipeline import traiter_video

APPARITION = 11  # entre deux analyses (pas de 2 images)


def _dessiner(image, i):
    if i >= APPARITION:
        x = 20 + 6 * (i - APPARITION)
        cv2.putText(image, "Rue Nationale", (x, 140), cv2.FONT_HERSHEY_SIMPLEX, 1.5, (0, 0, 0), 3)


def _textes_lus(ocr, image):
    return " ".join(d.texte or "" for d in ocr.detect(image)).lower()


@pytest.mark.slow
def test_aucune_image_ne_laisse_lire_le_texte(make_video, tmp_path):
    entree = make_video(n=40, fps=10.0, size=(640, 240), draw=_dessiner)
    ocr = TextDetector(conf_min=0.0)

    cap = cv2.VideoCapture(str(entree))
    for _ in range(20):
        ok, image = cap.read()
    cap.release()
    assert "nation" in _textes_lus(ocr, image)  # le test sait détecter une fuite

    cfg = SessionConfig(charte="Tout public. Jamais de nom de rue.", fps_analyse=5.0)
    res = traiter_video(entree, tmp_path / "out.mp4", cfg, Perception([TextDetector(0.5)]), RulesDecider(cfg))

    cap = cv2.VideoCapture(str(res.sortie))
    fuites, n = [], 0
    while True:
        ok, image = cap.read()
        if not ok:
            break
        lus = _textes_lus(ocr, image)
        if "nation" in lus or "rue" in lus:
            fuites.append((n, lus))
        n += 1
    cap.release()
    assert n == 40
    assert fuites == []
```

````markdown
# IRL Guard

Bloqueur de contenu pour lives IRL. À partir d'une vidéo enregistrée, IRL Guard masque les plaques d'immatriculation, les visages et les textes sensibles (noms de rue, numéros, données personnelles, insultes), et bascule sur un écran de pause quand le contenu est grave.

La perception repose sur des détecteurs pré-entraînés (YOLO, NudeNet, RapidOCR). La décision dépend du contexte : un decision model ([Laya](https://unsloth.ai/docs/models/decision-laya)) lit la charte de la chaîne, écrite en langage naturel, et décide pour chaque élément détecté. À détection identique, « Rue Nationale » est floutée en balade, mais déclenche une pause en mode domicile.

## Installation

```bash
uv sync
```

Laya est servi par l'app Unsloth :

1. Sous Windows, installer l'app avec `irm https://unsloth.ai/install.ps1 | iex`.
2. Dans l'app, ouvrir Settings → API → **Decision API**, activer *Serve requests* et choisir le modèle multilingue.
3. Activer *Keyless API access* pour localhost, ou renseigner `laya.cle` dans la config.

## Utilisation

```bash
uv run irl-guard process clip.mp4 --config configs/exemple.yaml --out sorties/clip_protege.mp4 --debug-overlay
uv run irl-guard process clip.mp4 --config configs/exemple.yaml --out sorties/clip_regles.mp4 --decider rules
uv run irl-guard replay sorties/clip_protege.jsonl clip.mp4 --config autre_reglage.yaml --out sorties/rejeu.mp4
```

Fichiers produits :

- la vidéo protégée ;
- `<out>.jsonl`, le journal (détections, `state` envoyés, décisions) ;
- avec `--debug-overlay`, `<out>_debug.mp4`, qui affiche les boîtes, les pistes, le texte lu et les probabilités.

⚠️ La vidéo de debug affiche le texte OCR en clair : elle sert à l'analyse, jamais à la diffusion.

## Fonctionnement

1. **Échantillonnage.** 3 images par seconde par défaut. Une image presque identique à la précédente réutilise son analyse.
2. **Perception.** YOLO COCO, détecteurs de visages et de plaques, NudeNet et RapidOCR.
3. **Suivi.** ByteTrack par classe, avec le texte OCR accumulé par piste.
4. **Décision.** Les visages et les plaques sont toujours masqués. Les textes et les objets ambigus sont jugés par le décideur, une fois par piste et par texte.
5. **Hystérésis.** La pause commence immédiatement et ne se termine qu'après plusieurs analyses calmes.
6. **Rendu.** Les masques sont interpolés entre deux analyses, et une piste perdue garde son masque quelques analyses. L'audio est coupé pendant les pauses.

- Pas de détection d'armes à feu (absentes de COCO), pas d'analyse audio.
- L'OCR peine sur le texte stylisé ou flou.
- Les décisions de Laya ne sont pas encore fine-tunées sur ce domaine.
````
